# v1.1 标题页与开机标志高清纹理

## 现象与处理

v1.1 首发的高清 UI 包里，标题页背景、Fate/EXTRA 标志、版权与 PRESS START，以及 TYPE-MOON / Marvelous 开机标志仍使用从 PSP 原始图块放大的替代图，所以在 PPSSPP 高渲染分辨率下仍然发虚。

已从 Fate-Extra-HD 日版 `NPJH50247` 纹理包中按游戏 TXB 图块的 xxh64 哈希逐块匹配 8 倍 PNG，并把对应的 xxh64 与 quick 映射写入 UI 包。范围为标题背景与背景叠层、标题标志、版权、PRESS START 和开机厂商标志。源项目为 [Fate-AI-HD-Team/Fate-Extra-HD](https://github.com/Fate-AI-HD-Team/Fate-Extra-HD)；来源的韩文化整合包说明其 HD 图像资源来自该项目。

标题 logo 图块 25、26、27 含有韩文副标题，导入器明确跳过这三块，并保留 UI 包原有的非韩文图块，避免把韩文带入简体中文包。其余标题标志主体及纯图形背景使用源包 256×256 图块（对应 PSP 32×32，8 倍）。

## 复现

从工程根目录执行，Python 需安装 Pillow、numpy 与 xxhash：

```sh
python3 scripts/pipeline/import_fate_extra_title_startup_hd.py \
  --source-pack work/extracted/packages/pack \
  --hd-pack work/research/hd-texture-pack/extracted/Fate-Extra-Korean-HD-v55/NPJH50247 \
  --pack-root work/release-v1.1/stage/ui-hd \
  --report work/release-v1.1/reports/title-startup-hd-import.json
```

导入报告记录命中的 TXB、图块索引、两种哈希、源图片与排除原因。导入器在写出前校验原始纹理哈希；写出后回读图像尺寸和映射。此次结果为 735 个图块、733 个唯一 PNG、1,466 条哈希映射。

## 运行时验证

安装更新后的 UI 包后需完全退出并重启 PPSSPP，确认纹理替换启用，再检查开机 TYPE-MOON / Marvelous 标志与标题页。PPSSPP 运行时验证结果写入 `work/release-v1.1/reports/title-startup-hd-runtime.md`。
