### 夜间：可重建工程（v0.16）

- 盘点解包树：15,964 个文件 / 1.67 GB，拆成 `cpk` 1,543 + `packages` 14,419 + 清单。

- 固化变更集：375 个文件 / 71.9 MB，逐文件 SHA-256，覆盖字库、小字表与 366 个 UI 包。
- 生成解包清单：路径/大小/校验和，gzip 后 160 KB，用于核对自备 ISO。
- 实现 `scripts/quick/quick.py`：bootstrap / rebuild / text / image / overlay / inventory / status / verify。
- 端到端实测：从日版原盘出发，`bootstrap` + `rebuild` 产出可校验的 CPK 与 ISO。
- 修正解包路径：不再依赖挂载点，直接按 ISO9660 解析取出 `data.cpk`。

**阶段结论**：工程从"记录过程"变成"可被任何人接手重建"。

  但 PSP 的 CLUT 上传按对齐地址取，后续成员全部错位。改为按 16 字节补零对齐。

### 上午–下午：v18 现场动作表与菜单图

- 现象：场景界面里的动作表仍是「話す」「調べる」，v17 字库还缺原生「話」字，界面上只剩「す」。
- 根因：这 24 槽固定动作表在场景 DAT 内，位于固定哨兵之后，不在剧情文本提取范围内。
- 修复：从实际 v17 CPK 读出 808 个场景包，改写 807 个非空 DAT（851 条包装条目），
  只替换哨兵后的 280 字节共用表；DAT 大小、指针、脚本与其余字节不动；47 个用字先做字库回读。
- `ICON0/PIC0/PIC1` 菜单图汉化并写回 ISO 外资源区；发布视频素材与镜头审计同步完成。
- 产物：`Fate_Extra_CN-v18.iso` 1,461,848,064 字节，内嵌 `data.cpk` 1,348,403,600 字节。

**阶段结论**：内容层到 v18；剩下的主要风险是运行时行为（ruby 第三页、超大 ISO 在 CFW 上的兼容性）。
