### 夜间：可重建工程（v0.16）

- 盘点解包树：15,964 个文件 / 1.67 GB，拆成 `cpk` 1,543 + `packages` 14,419 + 清单。
- 结论：1.67 GB 里只有 375 个文件被改过，其余可由 ISO 精确重现；因此只把**变更集**入库。
- 固化变更集：375 个文件 / 71.9 MB，逐文件 SHA-256，覆盖字库、小字表与 366 个 UI 包。
- 生成解包清单：路径/大小/校验和，gzip 后 160 KB，用于核对自备 ISO。
- 实现 `scripts/quick/quick.py`：bootstrap / rebuild / text / image / overlay / inventory / status / verify。
- 端到端实测：从日版原盘出发，`bootstrap` + `rebuild` 产出可校验的 CPK 与 ISO。
- 修正解包路径：不再依赖挂载点，直接按 ISO9660 解析取出 `data.cpk`。

**阶段结论**：工程从"记录过程"变成"可被任何人接手重建"。
