# Fate/EXTRA 简体中文 v1.2

v1.2 修复了实机照片中确认的 UI 残字，并统一了读取存档菜单的中文字形。该版本另提供刷新过纹理映射的 PPSSPP 高清 UI 包与单一配置的场景/UI 合并包。

## 下载

- `Fate_Extra_CN-v1.2.iso`：用户自编译的日版简中 ISO，作为 GitHub Release 附件提供；不存入 Git 仓库。
- `Fate_Extra_CN-v1.2-PPSSPP.iso`：与上面相同的汉化 CPK，另将礼装 MP 动态效果句写入解密 EBOOT；仅供 PPSSPP/支持解密 ELF 的环境。PSP 实机请使用保留原版加密 EBOOT 的普通 ISO，但该版 EBOOT 生成的 MP 效果句仍为日文。
- `Fate_Extra_CN-v1.2-HD-Combined-Pack.zip`：完整场景与中文 UI 合并包，使用唯一 `textures.ini`。
- `Fate_Extra_CN-v1.2-HD-Combined-Pack-Mobile.zip`：半分辨率场景与中文 UI 合并包，适合显存较紧张的设备。
- `HD-Texture-Pack-Install-Guide.md`：安装、回退与故障排查说明。以上纹理包只适用于 PPSSPP，不适用于实体 PSP。

两个合并包都同时包含场景纹理和中文 UI，且各自只带一个 `textures.ini`，不需要把不同包的配置互相覆盖。普通用户选择完整或移动版其中一个即可；纹理包只适用于 PPSSPP，不适用于实体 PSP。

工程已同步到 GitHub `main`。目前先维护到 v1.2；有兴趣继续校对或扩展的玩家可以 fork 工程。
