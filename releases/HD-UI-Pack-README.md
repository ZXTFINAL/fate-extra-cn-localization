# Fate/EXTRA 简体中文高清 UI / 字库包 v1.2

本包适用于 PPSSPP 纹理替换。包含正文、ruby 注音、过场诗句的 8 倍字库，以及按原界面字形风格制作的中文 UI、教程、标题和开场纹理。它不修改 ISO 或游戏存档，不能在实体 PSP 上加载。

推荐普通用户选择发布页的完整或移动版合并包之一；合并包已包含本 UI 包，使用一份 `textures.ini`。

## 单独安装 UI 包

1. 完全退出 PPSSPP，备份并移走旧的 `PSP/TEXTURES/NPJH50247` 目录。
2. 解压本 ZIP，把 `NPJH50247` 文件夹放到当前记忆棒的 `PSP/TEXTURES/` 中。
3. 确认配置路径是 `PSP/TEXTURES/NPJH50247/textures.ini`，在 PPSSPP 图形设置中启用纹理替换，然后重启模拟器。
4. 渲染分辨率按设备性能设置；较高分辨率能显示更多纹理细节，但也会增加 GPU 负载。

如果已有兼容的场景包，保留其目录，运行本包的安装器合并映射：

```sh
python3 install.py --target "/路径/到/PSP/TEXTURES/NPJH50247"
```

不要直接复制两个独立包的同名 `textures.ini`。安装器保留现有场景映射，按当前的 `xxh64` 或 `quick` 模式加入中文 UI，并备份旧配置。

## 版本与覆盖范围

- 当前映射由 v1.2 最终 CPK/TXB 重新生成；较旧构建的兼容键仅作为补充，当前映射优先。
- 包含 16 页正文、4 页注音小字（678 字形）和 2 页诗句字库（453 字形）。
- 保留对状态页 E、问号等资源的兼容映射；菜单文字按组件使用相应字形、字宽与基线。
- 标题与开机标志的部分高分辨率图块来自社区 Fate/EXTRA 高清包，按日版 TXB 原始哈希逐项匹配；含韩文副标题的图块已排除。
- 更改汉化字库或 UI 后，可能需要重新生成纹理映射。适用于日版游戏 ID `NPJH50247`。
