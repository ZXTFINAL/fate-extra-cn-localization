# v0.15.0 — 工程基线 + v15 资源预备

这是本仓库的**第一个公开版本**：把《Fate/Extra》PSP 日版汉化工程的全过程、方法论、脚本、翻译主表与审计证据整理成可复现的仓库。

> 本版本发布的是**工程与翻译数据**，不是游戏 ISO。除 `data/evidence/poem/` 下最小复现切片外，不包含游戏本体或完整商业素材。

## 怎么用

### 只想读过程

从 `README.md` → `docs/01-pipeline.md` → `docs/09-pitfalls.md`。

### 想复现构建

1. 自备日版 ISO（`NPJH-50247`）；
2. 按 `docs/01-pipeline.md` 的 S1–S8 执行；
3. 字体渲染需要 macOS（AppKit）与 Hiragino Sans GB W6；
4. 用 PPSSPP 验证。

### 想继续翻译/校对

1. 读 `AGENT.md` 的约束与流程；
2. 从 `ROADMAP.md` 的 lane 2/3 接手；
3. 修正写 `id / zh_cn / reason`，不要直接改主表；
4. 遵守 `docs/08-quality-review.md` 的证据标准。

## 已知限制

- **v15 尚未回写 ISO**：本版本不提供 v15 ISO。
- **ruby 第三页**：PAK 可存 3 页，但运行时是否有页数上限未由 EBOOT 证实，需实机确认。
- **教程截图内部 UI**：教程标题/正文已译，截图中的原游戏 UI 仍为日文。
- **lane 2/3**：尚未开始，全量语义校对未完成。
- **范围外资源**：模型贴图、场景看板、视频字幕、PSP 系统对话未盘点。
- **实机回归**：仅 PPSSPP 抽检，非全流程/全分支。

因此本版本定位是**工程基线 + 资源预备**，不是"完美汉化版"。
