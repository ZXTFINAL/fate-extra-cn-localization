# Fate/EXTRA 简体中文 v1.3

## 主要修复

- 修正高清字库部分页面模糊：v1.2 ISO 内 CPK 与高清 UI 纹理包采用了不同版本，导致部分 PPSSPP 纹理缓存键不匹配。v1.3 正文、注音、诗文和 UI 映射均从与 ISO 相同的最终 CPK 重建；合并包 manifest 可核对 CPK SHA-256。
- 修正 `男子トイレだ。` 误译为“墙上贴着各班级的名单”，改为“男厕。”。紧接的“现在也没什么特别要做的事”译文语义正确，保留。
- 上下文审校补丁现在必须带可验证的原文和源文件位置，降低相同文本 ID 被错误上下文补丁覆盖的风险。
- 重新生成场景与简体中文 UI/字库的单配置合并纹理包，提供完整版和移动版。

## 下载资产

- `Fate_Extra_CN-v1.3.iso`：标准 ISO。
- `Fate_Extra_CN-v1.3-PPSSPP.iso`：内含解密 EBOOT，仅面向 PPSSPP/兼容自制系统环境；不承诺适用于零售 PSP 固件。
- `Fate_Extra_CN-v1.3-HD-Combined-Pack.zip`：完整版场景 + 中文 UI/字库。
- `Fate_Extra_CN-v1.3-HD-Combined-Pack-Mobile.zip`：移动设备场景版 + 同一套高清中文 UI/字库。
- `HD-Texture-Pack-Install-Guide-v1.3.md`：安装、缓存清理和错误排查说明。
- `SHA256SUMS.txt`：ISO 与纹理包校验值。

ISO 是基于日版资源构建的非官方简体中文修改版，并非官方镜像。原游戏及素材权利归各自权利人所有。

## 安装注意

纹理包只适用于 PPSSPP。纹理包必须与 v1.3 ISO 配套使用；完整版与移动版二选一。退出 PPSSPP 后先移走旧的 `PSP/TEXTURES/NPJH50247` 目录，再安装所选的一个合并包，并开启 PPSSPP 纹理替换。不要将独立包或旧版 `textures.ini` 覆盖到合并包上。

## 核验范围

两份 ISO 内 CPK 的 SHA-256 均为 `7505dc81e9190bdbc2247fd2aee5ddcf3400e0f2ea17b9d8fc885cdfb4f9596b`。完整与移动纹理包通过 ZIP CRC、INI 回读、映射资源存在性和 CPK 版本匹配静态校验；正文 16 页/4,096 字位与注音 4 页纹理均由本版 CPK 重建。

本版没有进行 PPSSPP 全流程运行或 PSP 实机测试。全量剧情语境人工复校仍未完成；已修复本次确认的问题，不代表全部文本和图片都已逐条校对。

个人精力有限，v1.3 是当前维护版本。工程与构建脚本已推送到 GitHub；欢迎感兴趣的玩家 fork 后继续维护与校对。
