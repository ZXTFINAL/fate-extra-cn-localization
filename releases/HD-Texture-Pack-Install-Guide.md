# Fate/EXTRA v1.2 高清场景与文字纹理包安装教程

本次提供完整版和移动设备版。两者都是**单 ZIP 合并包**，都把场景纹理和中文 UI 字体合并到一份 `textures.ini`。设备显存充足选完整版；手持设备若遇到黑纹理、黑屏或卡顿，先试移动版。另有完整版场景包和 UI 包可分开安装。纹理包只适用于 PPSSPP 模拟器，不适用于实体 PSP：

- `Fate_Extra_CN-v1.2-HD-Combined-Pack.zip`：推荐。场景纹理与中文 UI/字库共用一份配置，直接安装即可。
- `Fate_Extra_CN-v1.2-HD-Combined-Pack-Mobile.zip`：移动设备版，沿用 PPSSPP 论坛作者提供的半分辨率场景纹理；中文 UI 和字库保持高清。
- `Fate_Extra_CN-v1.2-HD-Scene-Pack.zip`：日版场景、模型与特效高清纹理。
- `Fate_Extra_CN-v1.2-HD-UI-Pack.zip`：简体中文 UI、教程文字、正文汉字字库和 ruby 注音小字字库。

完整版和移动设备版二选一，不要同时安装。移动版纹理来源为 [PPSSPP 论坛 Fate Extra Texture Pack](https://forums.ppsspp.org/showthread.php?tid=30052) 的实验性移动版本；它减少场景纹理分辨率和显存占用，但不能保证解决所有设备或 ISO 的错误。

纹理包适用于日版《Fate/EXTRA》`NPJH-50247`。它们只供 PPSSPP 的纹理替换功能使用，不修改 ISO、游戏存档或 PSP 主机文件。

## 推荐方式：安装合并包

1. 完全退出 PPSSPP。先将现有 `PSP/TEXTURES/NPJH50247` 整个文件夹备份到别处。想避免旧韩文界面残留时，建议用干净目录。
2. 解压完整版或移动版合并包，把其中的 `NPJH50247` 文件夹整体放到当前记忆棒的 `PSP/TEXTURES/` 下。确认最终路径为 `PSP/TEXTURES/NPJH50247/textures.ini`。
3. 启动 PPSSPP，在「设置 → 图形」打开纹理替换。场景 KTX2 纹理需要 PPSSPP 1.15 或更新版本。渲染分辨率按设备能力设置：手持设备先从 2x 或 3x PSP 开始；有余量再提高。
4. 完全退出并重新启动 PPSSPP，再载入《Fate/EXTRA》检查文字与场景。

## 分别安装完整版场景包与 UI 包

1. 完全退出 PPSSPP。先将现有 `PSP/TEXTURES/NPJH50247` 整个文件夹备份到别处。想避免旧韩文界面残留时，建议在 PPSSPP 的纹理目录中新建干净的 `NPJH50247` 文件夹；不要把旧整合包与本包混在一起。
2. 解压场景包，将其中的 `install.py` 与 `NPJH50247` 文件夹放在同一个位置。运行：

   ```sh
   python3 install.py --target "/路径/到/PSP/TEXTURES/NPJH50247"
   ```

3. 解压 UI 包，在同一目标目录运行 UI 包自己的安装器：

   ```sh
   python3 install.py --target "/路径/到/PSP/TEXTURES/NPJH50247"
   ```

   先安装场景包，再安装 UI 包。两个安装器会合并纹理映射，并保留目录中没有被映射覆盖的其它纹理文件。
4. 启动 PPSSPP，在「设置 → 图形」打开纹理替换，并按设备能力设置渲染分辨率。载入《Fate/EXTRA》后再检查文字与场景。
5. 若 PPSSPP 已经运行过游戏，完全退出并重新启动，以便重新载入纹理缓存。

不要把两个独立压缩包内的 `textures.ini` 直接复制到同一目录：它们文件名相同，后复制的会覆盖先复制的，最终只剩一包的映射。若手动安装，请运行两包各自的 `install.py`，并按“场景包后 UI 包”的顺序操作；也可直接用推荐的合并包。

PPSSPP 的纹理目录取决于使用的记忆棒位置。通常为 `PSP/TEXTURES/NPJH50247`；请在「设置 → 系统」查看当前的记忆棒文件夹。macOS、Windows 与 Android 的完整路径会因安装方式和自定义设置而不同。

## 检查效果

- 按照你自己的 PPSSPP 或手柄控制设置打开菜单、查看对话正文；本教程不规定按键映射。
- 本包正文汉字字库和注音字库分开替换。注音字库共 4 页，8 倍制作，支持日文假名及 v1.2 汉化文本需要的中文小字。
- 查看背景、模型与特效时确认场景包也已安装。场景包使用日版 `xxh64` 哈希；UI 安装器会读取目标目录当前配置并选择对应的哈希映射。

## 与其它纹理包共用和关闭对比

场景包与 UI 包可以放在同一个 `NPJH50247` 目录。UI 包只覆盖它列出的中文 UI 与字库哈希；目录里没有被覆盖的哈希仍可能由其他纹理包提供。若看到韩文或重复文字，先退出 PPSSPP，再将现有目录备份并用干净目录只安装本教程中的两个包。

要对比两包合并后的整体效果，在「设置 → 图形」临时关闭「纹理替换」，重新载入游戏后观察原始纹理；对比完成后重新开启纹理替换并重启 PPSSPP。这个开关会同时关闭全部纹理替换，不会删除纹理包文件。

## 黑屏或 PPSSPP 报错时的排查

1. 先确认使用的是同一版 v1.2 ISO，并完全退出 PPSSPP 后用干净的 `NPJH50247` 目录重装合并包，排除旧纹理和被覆盖的配置文件。
2. 保持原纹理包和其它图形设置不变，在同一存档位置临时关闭 PPSSPP 的「纹理替换」并重进该场景。如果关闭后恢复，问题与纹理替换路径有关；如果仍黑屏，继续记录设备和模拟器信息，不要先归因于纹理包。
3. 若关闭纹理替换后正常，使用干净的 `NPJH50247` 目录只安装 UI Pack（不要保留 `SceneHD`）复测。UI Pack 正常而合并包黑屏，说明问题范围在场景纹理或设备/图形后端兼容性；诊断期间可继续用 UI Pack 查看高清文字。
4. 再单独换成移动版合并包复测，保持同一渲染分辨率和其它设置不变。若移动版恢复正常，说明设备对完整版场景纹理的兼容性或资源压力值得优先排查，但仍不能单凭此结果认定根因。之后可单独降低渲染分辨率再测。PPSSPP 论坛曾说明，显存不足时替换纹理可能显示为黑色；这是可能原因之一。
5. **蓝色 CPU 错误页与图像黑屏分开排查。** 若页面显示 `Bad Execution Address`、`PC = 00000000`，先在同一存档关闭纹理替换复测；然后仅将 CPU Core 从 JIT 临时切换为 Interpreter 再试。如果 Interpreter 可继续而 JIT 仍崩溃，记录该差异；如果两种核心都崩溃且关闭纹理替换也无效，再查 ISO 与游戏数据。修改版 ISO 显示 `CRC not identified` 本身不能证明镜像损坏；PPSSPP 官方排障说明未知 CRC 仍可能是有效镜像，建议核对文件并确认直接从 ISO 启动：[PPSSPP 游戏无法加载排障](https://github.com/hrydgard/ppsspp-site/blob/main/docs/troubleshooting/game-wont-load.md)。
6. 反馈故障时请记录 PPSSPP 版本、设备型号和系统、图形后端、CPU Core、使用的纹理包、纹理替换开关、ISO 的 SHA-256，以及触发前的具体操作。`PC = 00000000` 只说明模拟器报告了无效跳转；单凭这一项不能判断 ISO、游戏数据或模拟器哪一项是根因。

请不要在故障出现时同时切换多个设置；每次只改变一个变量，才容易定位原因。以上是定位步骤，不代表已确认任何一项是根因。

## 回退

退出 PPSSPP，并用安装前备份的 `NPJH50247` 文件夹恢复原状。安装器写入前也会分别保存 `textures.ini` 备份；不要只恢复配置而保留相互不匹配的旧、新纹理文件。

## 校验

下载发布页提供的 `SHA256SUMS.txt`，在 macOS/Linux 运行 `shasum -a 256 -c SHA256SUMS.txt`，在 Windows PowerShell 用 `Get-FileHash -Algorithm SHA256 <文件>` 对下载文件进行核对。
