# Fate/Extra 简体中文补丁 v1.0

这是首个面向玩家的 v1.0 补丁包。请使用自己合法取得的 PSP 日版《Fate/Extra》（`NPJH-50247`）ISO，按补丁包内 README 的步骤重建。

## 下载

- `Fate_Extra_CN-v1.0-patch.zip`：翻译表、字库映射、580 个汉化资源覆盖层、重建脚本与所需解包清单。
- `SHA256SUMS.txt`：补丁包校验值。

本 Release 不提供 ISO、CPK 或未修改的游戏资源。

## v1.0 内容

- 19,711 条文本记录，其中 19,709 条有译文；另有两条原文为空白。
- 1,640 个正文/菜单字形别名，另有诗文专用字形映射。
- 580 个被修改过的资源文件，合计 72,883,600 字节，涵盖字库、UI、物品、技能、情报矩阵与诗文资源。
- 修复 5 条截图确认的异常硬换行，并通过 14 处实际引用回读。
- 更新发布文档、资源 manifest 和 v1.0 静态校验记录。

## 重建

将自己持有的日版 ISO 放到 `iso/original.iso`，然后运行：

```sh
python3 scripts/quick/quick.py bootstrap --iso iso/original.iso
python3 scripts/quick/quick.py rebuild
```

输出 ISO 位于 `work/build/Fate_Extra_CN.iso`。更多细节见 `docs/11-quick-rebuild.md`。
