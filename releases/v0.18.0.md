## 三个值得记的修复

1. **现场动作表**：`話す` / `調べる` / `校舎　B1Fへ` 这些界面动词藏在场景 DAT 尾部的固定 24 槽表里，
   不在剧情文本提取范围。v18 改写 807 个非空场景 DAT（851 条包装条目），只替换哨兵后的
   280 字节共用表，其余字节与指针不动。
2. **TEX 成员对齐**：逻辑表增长 2 字节会让后续 TEX/CLUT 整体错位，宿主回环测不出来，
   PSP 上直接花屏。现在按 16 字节补齐。
3. **诗文分配器漂移**：16px 网格错位修复后，别名分配出现回归；补差量校验与非诗文别名审计。

## 怎么用

```sh
cp /path/to/日版.iso iso/original.iso
python3 scripts/quick/quick.py bootstrap      # 一次
python3 scripts/quick/quick.py rebuild        # 文本 → 动作表 → 写回 ISO
```

`rebuild` 现在是四段：套变更集 → 文本重建 → 动作表注入 → 写回 ISO。
动作表必须在文本之后，顺序反了会被覆盖回日文。
