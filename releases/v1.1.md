# Fate/EXTRA v1.1 高清纹理包

本次发布提供配套 PPSSPP 使用的高清纹理包与安装教程。纹理包不包含游戏 ISO；请使用自己的《Fate/EXTRA》日版 `NPJH-50247` v1.1 简体中文构建。推荐普通用户下载合并包，避免两个同名 `textures.ini` 被复制覆盖。

## 下载文件

- `Fate_Extra_CN-v1.1-HD-Combined-Pack.zip`（约 882 MB）：推荐的一体包，含场景纹理与中文 UI/字库，使用唯一一份 `textures.ini`。
- `Fate_Extra_CN-v1.1-HD-Scene-Pack.zip`（约 683 MB）：日版场景、角色模型与特效纹理；不含 UI、教程或字库。
- `Fate_Extra_CN-v1.1-HD-UI-Pack.zip`（约 196 MB）：简体中文界面、正文、状态/商店/提示/教程纹理和字库。包含 16 页正文汉字纹理、4 页独立 ruby 注音纹理（678 个字形），以及 `xxh64` / `quick` 两类哈希映射。
- `HD-Texture-Pack-Install-Guide.md`：安装次序、PPSSPP 设置、画面检查与回退说明。
- `Fate_Extra_CN-v1.1-HD-Texture-Packs-Guide-zh-CN-No-Voice.mp4`：双包效果、修复项目与安装步骤视频；仅有背景音乐，无配音。
- `Fate_Extra_CN-v1.1-HD-Texture-Packs-Guide-zh-CN.srt`：与视频时间轴同步的独立中文字幕，可用于 B 站字幕上传。
- `SHA256SUMS.txt`：纹理包、视频与安装说明的 SHA-256 校验值。

## 快速安装

1. 退出 PPSSPP，备份或移开现有 `PSP/TEXTURES/NPJH50247`，避免旧韩文纹理残留。
2. 推荐解压 Combined Pack，并把其中的 `NPJH50247` 文件夹放入 `PSP/TEXTURES/`。
3. 如分别安装 Scene Pack 和 UI Pack，必须先运行场景包的 `install.py`，再运行 UI 包的 `install.py`。不要把两包里的同名 `textures.ini` 直接复制到一起，否则后复制的配置会覆盖前一份。
4. PPSSPP 1.15 或更新版本的「图形」中开启纹理替换，渲染分辨率可设为 `8× PSP`，然后完全退出并重启 PPSSPP。
5. 启动游戏后，按你自己的 PPSSPP 或手柄控制设置打开菜单、查看正文；具体按键因设备和个人设置而异。

详细步骤和不同系统的记忆棒目录见 `HD-Texture-Pack-Install-Guide.md`。

## 已核对范围

- PPSSPP 1.20.4、8× 渲染下，用同一存档的同一段对话进行了开关对照：关闭纹理替换后回到原始低分辨率纹理；重新开启后显示替换后的文字与立绘。
- 正文纹理页、ruby 图集及两种哈希映射已打入 UI Pack；ruby 字库中具体某句台词的运行时显示尚未逐句核验。
- 单独包与合并包的纹理映射均已静态检查；Combined Pack 将两套映射合并为一份配置。PPSSPP 的「纹理替换」开关可用于对比原始画面；它会同时关闭全部纹理替换。配套视频展示双包效果、修复图片和安装设置。
